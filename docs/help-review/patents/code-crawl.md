# Patents and lexes: code crawl (2026-09-26)

Refresh of `docs/help-manual-inventory.md` §A.3 for `guide-map.md`. Line numbers at 7b8f0c0. Faction trees,
laws and government are excluded. Internal names: a bought lex is a `doctrine`, an active lex is a `policy`.
