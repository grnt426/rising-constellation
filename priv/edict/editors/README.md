# Edict editor kit {{version}}

Write Tetrarchy Falls scenarios in your own editor. Everything here is
generated by the game from the same catalog its checker uses, so the names,
docs and signatures you see are exactly what the game accepts.

What you get, depending on the editor:

- highlighting (keywords, actions, builtins, world paths, durations such as
  `15s`, percentages, text holes `{n}`)
- completion: builtins, actions, world fields (`player.income.` lists
  `credit`, `technology`, `ideology`), setup fields, the values a place
  takes (`give("` offers the resources, `tone: "` the tones, `grant_patents`
  the patent keys), names in scope, and snippets for every part of a
  scenario
- hover docs, signature help, an outline of the scenario, go to definition
- the game's own checks for text it can't read: unclosed quotes and
  brackets, unknown escapes, hidden text-direction characters

The full check (names, types, setup values) happens in the game. In the
Scenario Workshop, **File > Open file** loads a script, and **File > Link a
file** (Chrome and Edge) keeps the workshop in step with the file while you
edit it here: save in your editor and the nodes, problems and simulation
update.

Files end in `.edict`.

## The language at a glance

Edict is a small language made for this game, not a cut-down version of
another one. If you program, it reads like Python written with braces,
borrowing a few things from others:

| From | In Edict |
|---|---|
| Python | `# comments`, `and` `or` `not`, `for x in xs { }`, `len(xs)`, `str(n)`, `1_000_000` |
| JavaScript | `{ … }` blocks, `x => x * 2`, `{key: 1}` records, `let` and `var` |
| Swift, Go | `if x > 1 { }` without parentheses, `nil`, named arguments `notify("Hi", tone: "good")` |
| Rust | `fn total(a, b) { return a + b }` |

Where it differs from what you might expect:

- No `;`: one statement per line.
- Conditions must be `true` or `false`; there is no truthy `0` or `""`.
- Every number is a decimal and `/` never truncates. `%` makes a percent
  (`25%` is `0.25`), so the remainder is `mod(17, 5)`. Durations are
  numbers of seconds: `15s`, `1m30s`, `1h`.
- Values, not references: `let b = a` copies, and `push(xs, 4)` returns a
  new list.
- Functions, not methods: `map(xs, f)`, `len(xs)`, `sort_by(xs, f)`. Text
  takes holes, `"wave {n}"`; the inline if is `if c then a else b`.
- Lists start at `0`; `range(1, 3)` is `[1, 2, 3]`.
- No classes, imports, exceptions or files. A script declares a `setup`, a
  `score`, `var`s and `fn`s, and reacts to events (`on start`,
  `every 15s`, `at 10m`, `when …`, `on end`); it changes the game only
  through actions such as `give()` and `notify()`, within a step budget
  each second.

## VS Code, Cursor, VSCodium

1. Open the Extensions view.
2. In its `...` menu, choose **Install from VSIX...** and pick
   `edict-{{version}}.vsix`.

Everything above works, with no other setup.

## JetBrains IDEs (IntelliJ IDEA, WebStorm, PyCharm, Rider, …)

Highlighting:

1. **Settings > Editor > TextMate Bundles**, click **+**, and pick the
   `textmate` folder from this kit.

Completion, hover and the rest (needs [Node.js](https://nodejs.org) 18 or
later):

1. Install the free **LSP4IJ** plugin (Settings > Plugins > Marketplace).
2. **Settings > Languages & Frameworks > Language Servers**, click **+**.
3. Name: `Edict`. Command: `node "<this kit>/lsp/edict-lsp.js" --stdio`
   (the full path to the file).
4. On the **Mappings** tab, under **File name patterns**, add `*.edict`
   with language id `edict`.

## Notepad++

Highlighting (keywords and actions in bold, builtins, world values,
numbers and text in their own colors, comments in italics):

1. **Language > User Defined Language > Define your language...**, click
   **Import...** and pick `notepad++/Edict.xml`, or `notepad++/dark/Edict.xml`
   if you use a dark theme (Settings > Preferences > Dark Mode).
2. Restart Notepad++. `.edict` files open as Edict; for a file with another
   name, choose **Language > Edict**.

Completion with call tips:

1. Copy `notepad++/autoCompletion/Edict.xml` into the `autoCompletion`
   folder where Notepad++ is installed (usually
   `C:\Program Files\Notepad++\autoCompletion`; Windows asks for permission).
2. **Settings > Preferences > Auto-Completion**: turn on **Function and word
   completion** and **Function parameters hint on input**.

Notepad++ completes names and shows each function's parameters and doc as
you type `(`. It has no hover docs or context-aware completion; the
workshop's link (see above) fills that gap.

## Neovim, Sublime Text, Zed, Helix, Emacs

The language server in `lsp/` speaks the Language Server Protocol over
stdio. Run it with Node 18 or later:

```
node /path/to/kit/lsp/edict-lsp.js --stdio
```

and map it to `*.edict` files with language id `edict`. Two examples:

- **Neovim** (0.11+):
  `vim.lsp.config('edict', { cmd = { 'node', '/path/to/kit/lsp/edict-lsp.js', '--stdio' }, filetypes = { 'edict' } })`,
  `vim.lsp.enable('edict')`, and `vim.filetype.add({ extension = { edict = 'edict' } })`.
- **Helix** (`languages.toml`): a `[language-server.edict]` with
  `command = "node"` and `args = ["/path/to/kit/lsp/edict-lsp.js", "--stdio"]`,
  and a `[[language]]` named `edict` with `file-types = ["edict"]` and
  `language-servers = ["edict"]`.

For highlighting, editors that read TextMate grammars (Sublime Text, for
one) can use `textmate/syntaxes/edict.tmLanguage.json`.

## What's in the kit

| Path | What it is |
|---|---|
| `edict-{{version}}.vsix` | the VS Code extension |
| `textmate/` | the TextMate grammar and language settings, as a bundle |
| `lsp/edict-lsp.js` | the language server (`core.js` does the work, `catalog.json` is the language) |
| `notepad++/` | the Notepad++ language and auto-completion files |

`lsp/catalog.json` lists everything a script can name (builtins, actions,
world fields, setup fields, with docs and types), for anyone building
their own tools.

The kit only reads the text you're editing: it touches no other files and
makes no network calls.
